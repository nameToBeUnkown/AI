Junior Python Developer (FastAPI / Celery / FinTech)
Компанія: FinTech Startup на Djinni
Локація: Remote (Україна)
Зайнятість: Повна

Про проєкт:
Ми розробляємо платіжний агрегатор для малого та середнього бізнесу з високим щоденним навантаженням (понад 2 млн транзакцій на добу). Шукаємо амбітного Junior Python розробника, який готовий швидко зануритися у розробку надійного бекенду та асинхронної обробки фінансових операцій.

Вимоги:
- Впевнені знання Python 3.10+ (розуміння роботи інтерпретатора, ООП, типізація typing);
- Досвід роботи з асинхронним стеком: FastAPI або aiohttp, розуміння концепції Event Loop та async/await;
- Досвід роботи з реляційними базами даних: PostgreSQL (написання сирих SQL запитів, оптимізація індексів, транзакції, рівні ізоляції);
- Розуміння роботи черг повідомлень та фонових задач: Celery, Redis або RabbitMQ;
- Базові навички роботи з Docker та Docker Compose;
- Написання тестів: pytest, mock;
- Розуміння принципів RESTful API та базової веб-безпеки (JWT, CORS, Rate Limiting).

Буде плюсом:
- Досвід роботи з платіжними шлюзами або банківськими API;
- Розуміння мікросервісної архітектури;
- Досвід профілювання продуктивності коду (cProfile, memory_profiler).

Обов'язки:
- Розробка та підтримка ендпойнтів REST API платіжної платформи;
- Інтеграція з зовнішніми банківськими провайдерами;
- Оптимізація швидкодії важких запитів до бази даних;
- Покриття бізнес-логіки автоматичними unit- та integration-тестами.
