## 2. 5 згенерованих запитання

### Питання #1 [Database / Concurrency]

**❓** Уявіть, що у вас є Django view, який у межах @transaction.atomic оновлює два пов’язаних запису в PostgreSQL. Поясніть, як ви уникнете deadlock, коли одночасно два запити оновлюють ці записи у різному порядку.

**🎯 Що перевіряє лід:** Перевірити розуміння рівнів ізоляції, блокувань рядків, правильного порядку захоплення lock'ів та використання select_for_update для запобігання циклічних блокувань.

**🔑 Ключові тези:**
- Використання consistent ordering (наприклад, ORDER BY id) перед UPDATE
- select_for_update з explicit lock
- Встановлення isolation level READ COMMITTED або SERIALIZABLE
- Обробка IntegrityError та повторна спроба транзакції

**🔑 Ключові тези:**
